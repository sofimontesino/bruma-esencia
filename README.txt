BRUMA & ESENCIA - VERSION MEJORADA

Archivos principales:
- index.html
- style.css
- index.js
- imagenes/

Funciones agregadas con JavaScript:
1. Catálogo generado desde un array de productos.
2. Buscador de productos.
3. Filtro por precio.
4. Modal para elegir aroma.
5. Selector de cantidad.
6. Carrito lateral.
7. Sumar y restar cantidades.
8. Eliminar productos.
9. Vaciar carrito.
10. Cálculo automático del total.
11. Contador de productos en el carrito.
12. localStorage: el carrito se conserva aunque se recargue la página.
13. Mensajes visuales al agregar/eliminar productos.
14. Cierre de ventanas con ESC y haciendo clic fuera.
15. Botón de finalizar compra preparado para enviar el pedido por WhatsApp.

IMPORTANTE:
En index.js buscá:
const numeroWhatsApp = "5490000000000";

Reemplazá ese número por el número real de WhatsApp del emprendimiento.
Usá formato internacional, por ejemplo Argentina: 549 + código de área + número.
